# Contributing

Thanks for looking at `jochwacht-sbom`.

## Bug reports and ideas

Issues are welcome: a wrong version, a missing component, a build system we do not read yet. The most useful report contains the command you ran, the output you expected, the output you got, and (if you can share it) a small project that shows the problem. We read every issue. We do not promise a date.

Security problems go to office@innomatica.de, not into a public issue. See [SECURITY.md](SECURITY.md).

## Pull requests

We do not accept pull requests at the moment. Open an issue instead and describe the fix; if it is a good one we write it ourselves and credit you in the release notes if you like.

The reason is licensing, not unfriendliness. `jochwacht-sbom` is GPL-3.0-or-later, and Innomatica GmbH also uses parts of the same code in its own products under other terms. That only works while all the code is ours. Pull requests we cannot take in will be closed with a pointer to this page.

If this changes, we will introduce a contributor agreement and say so here before we open the door to pull requests.
